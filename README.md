STEO website, served by GitHub Pages from `main` at https://steo.app/.

- `index.html`: the landing page.
- `books/index.html`: the workbook page with the seven original Stripe payment links.
- `documents/`: the conceptual article and white paper PDFs.
- `assets/`: the avatar in AVIF and WebP formats.

All website content and images are hosted here. Google Fonts and Stripe remain external services.
The custom domain is `steo.app`; `www.steo.app` redirects to it through GitHub Pages.
